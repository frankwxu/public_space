# CYFI 725 AI-Agent Forensics Benchmark

This package contains four fictional, synthetic benchmark cases: text, image,
audio, and video. Give students the `student_package` directory only. Keep
`instructor_key` private until grading is complete.
Never commit or publish the instructor_key directory, answer key, generation provenance, or verification checklist.

Each team must use every instructor benchmark as Test A for its modality and
must propose an instructor-approved public or team-created case as Test B.
The files are teaching artifacts, not evidence from a real investigation.

Publish the `student_package` directory in the same GitHub repository as the final-project assignment. Before release, the instructor should inspect every file, confirm the answer
key, test the intended validation procedures, and regenerate `SHA256SUMS.txt`
if any file changes.
